## 客戶端版本與連線環境一起檢查

BoostNet 的接入資料涉及 AnyTLS 等協議名稱。本指南側重版本相容、裝置規則和日常使用邊界，幫助你在安裝後用清楚的步驟定位連線問題。

### 1. 確認當前協議支援

先看賬戶推薦的軟體與最低版本。即使軟體能匯入文字，也要確認其核心支援訂閱實際使用的協議。

### 2. 更新後保留對照

更新客戶端前記下版本與當前配置來源；更新後手動重新整理訂閱，檢查節點數量和錯誤提示。

### 3. 核對使用範圍

在大量下載、多人使用或路由器部署前閱讀服務條款，確認允許的裝置數與用途。

## 使用體驗如何檢查

把地區、運營商、時段、客戶端版本和目標應用保持一致，再比較連線結果。持續訪問、下載峰值和應用地區識別是不同指標；失敗或超時也應記錄。本文未釋出本次實測速度或實時節點狀態。

可在自己的裝置上記錄以下資訊，向賬戶支援反饋時隱藏個人憑據：

| 記錄項 | 填寫方式 |
| --- | --- |
| 裝置與網路 | 系統、客戶端版本、運營商及 Wi-Fi／移動資料 |
| 當前配置 | 節點名稱、訂閱更新時間，不記錄金鑰 |
| 具體場景 | 應用名稱、操作步驟與觀察到的結果 |
| 發生時間 | 註明日期、時間及所在時區 |

## BoostNet常見問題

### 匯入成功為什麼仍提示不支援協議？

匯入只代表配置被讀入。應用版本與網路核心可能獨立更新，需按接入說明同時核對。

### BoostNet 的網頁地址能當訂閱地址嗎？

不能。網頁用於進入賬戶，個人訂閱需要從登入後的配置區域獲取。

### 當前套餐價格與活動在哪裡確認？

進入賬戶檢視當前訂單，核對實付金額、付款週期、流量重置、有效期、裝置限制與售後條件。歷史截圖和舊優惠碼不能代替當前交易條款。
